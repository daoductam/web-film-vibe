# Specification: Caffeine Local Cache for Bucket4j Rate Limiting

## Goal
Resolve the `No Bucket4j cache configuration found - cache-to-use: null` startup crash on VPS environments when running Bucket4j with `spring.cache.type: redis`. By introducing Caffeine, Bucket4j will use a highly optimized in-memory cache for rate-limiting operations locally on the JVM, while the rest of the application can still use Redis for business caching.

## Proposed Changes

### Backend Dependencies (`pom.xml`)
- Add Caffeine cache dependency:
```xml
<dependency>
    <groupId>com.github.ben-manes.caffeine</groupId>
    <artifactId>caffeine</artifactId>
</dependency>
```

### Backend Configuration (`application.yml`)
- Add `bucket4j.cache-to-use: caffeine` configuration under the `bucket4j` block.

### Cleanup
- Delete the temporary draft class `RateLimitConfig.java` in `com.tamdao.web_film_backend.config`.

## Verification Plan
- Compile the backend application using Maven (`./mvnw compile`).
- Verify successful application startup without the `No Bucket4j cache configuration found` error.
