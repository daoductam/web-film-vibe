# 1. Context

**Problem:**
Dự án CineStream hiện tại đã có đầy đủ tính năng cơ bản, nhưng cần nâng cấp về mặt bảo mật (Security), hiệu năng (Performance) và trải nghiệm người dùng (UX) để đạt chuẩn một hệ thống "Production Ready" thực tế trước khi phát hành.

**Affected Modules:**
- `web-film-backend` — Bổ sung Refresh Token, Bucket4j, Caching, Audit Logging, Entity Graphs.
- `web-film-frontend` — Skeleton Screens, Toasts, WebP, Code Splitting.
- `web-film-android` — Offline Mode (Room DB, DownloadManager HLS), PiP Mode, Toasts/Skeletons.

**Non-Goals:**
- Tích hợp cổng thanh toán (Monetization) - thuộc scope của tính năng khác.
- Refactor hoàn toàn UI - chỉ cải tiến trải nghiệm hiển thị (Toasts, Skeletons).

---

# 2. Constraints

**Language:** Java 21 (Backend), TypeScript (Frontend), Kotlin (Android)
**Architecture:** Spring Boot, React 19, Jetpack Compose

**Rules:**
- Do NOT introduce new external dependencies unless strictly required (e.g., Bucket4j for Rate Limiting).
- Maintain backward compatibility with existing APIs to avoid breaking mobile/web simultaneously.

**Performance Budgets:**
- Latency: API Calls < 100ms (p95) after Caching.

# 5. Target Architecture

**Interaction Flow (Refresh Token):**
```
Client
  → AuthController.refreshToken(request)
    → JwtService.validateRefreshToken()
    → RedisTemplate.checkBlacklist()
  ← returns TokenResponse(newAccessToken, newRefreshToken)
```

**Interaction Flow (Rate Limiting):**
```
Client
  → RateLimitFilter (Bucket4j interceptor)
    → Check tokens for IP/User
    → Returns 429 Too Many Requests if exceeded
```

# 8. Task Specifications

## TASK-001: Backend: Refresh Token & Blacklist
**Description:** Add Refresh Token logic to Auth service and Redis blacklist for logout.
**Input:** User credentials / Expired token.
**Output:** `TokenResponse` / 401 Unauthorized.
**Responsibilities:** Implement `/refresh` endpoint, update logout to blacklist tokens.

## TASK-002: Backend: Rate Limiting
**Description:** Implement Bucket4j to rate limit API requests.
**Responsibilities:** 5 req/min for `/login`, 10 req/min for `/ai/chat`.

## TASK-003: Backend: Audit Logging
**Description:** Create `AuditLog` entity and Aspect/Interceptor to log Admin actions.

## TASK-004: Backend: JPA Entity Graphs
**Description:** Add `@EntityGraph` to `MovieRepository` to fetch relations (Category, Country) eagerly where needed, solving N+1.

## TASK-005: Backend: Redis Caching
**Description:** Enable `@EnableCaching` and use `@Cacheable` on `MovieService` read methods.

## TASK-006: Frontend: Skeleton Screens & Lazy Load
**Description:** Use Framer Motion/Tailwind for Skeletons, `React.lazy` for routing.

## TASK-007: Frontend: Global Toast Provider
**Description:** Implement Zustand store + UI component for global Toasts.

## TASK-008: Android: Offline Mode & Room DB
**Description:** Setup Room to cache Movie metadata, implement `Media3 DownloadManager` to download HLS streams.

## TASK-009: Android: PiP Mode
**Description:** Update `MainActivity` and `PlayerScreen` to support Android Picture-in-Picture mode on home button press.

# 9. Edge Cases

| # | Scenario | Expected Behavior | Handled In |
|---|----------|-------------------|------------|
| 1 | Refresh token is expired | Return 401, force re-login | TASK-001 |
| 2 | Rate limit exceeded | Return 429 Too Many Requests | TASK-002 |
| 3 | Storage full during download | Pause download, show Toast | TASK-008 |
| 4 | Network drops during download | Auto-resume when network is back | TASK-008 |
