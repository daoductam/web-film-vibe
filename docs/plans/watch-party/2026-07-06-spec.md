> **Ngày tạo:** 2026-07-06  
> **Trạng thái:** Draft — Chờ phê duyệt  
> **Ưu tiên:** Android First → Web Frontend  
> **Phạm vi:** Backend + Android + Web Frontend

---

## 1. Tổng quan

Watch Party là tính năng cho phép 2–50 người xem phim chung trong thời gian thực. Video được đồng bộ hoàn toàn (play/pause/seek) giữa tất cả thành viên, kèm theo chat text, voice/video call P2P, floating emoji reactions, AI chatbot tương tác, và hệ thống spoiler alert.

### Mục tiêu
- Tạo trải nghiệm xem phim chung như ngồi trong rạp cùng bạn bè
- Tương tác real-time: chat, voice, video, reactions
- AI Bot hỗ trợ trả lời câu hỏi về phim đang xem
- Hỗ trợ cả phòng công khai (Public) và riêng tư (Private)

### Thứ tự phát triển
1. **Phase 1 — Android Core:** Room CRUD, Lobby, STOMP WebSocket, Synced ExoPlayer, Basic Chat
2. **Phase 2 — Android Rich Features:** WebRTC Voice/Video, Floating Reactions, AI Bot, Spoiler, Countdown
3. **Phase 3 — Web Frontend:** Mirror tất cả tính năng sang React
4. **Phase 4 — Polish:** PiP, Push Notifications, Deep Links, Watch Party History

### 3.2 Redis State (Ephemeral — Real-time)

```
# Trạng thái video hiện tại của phòng
watchroom:{roomId}:state → HASH {
  currentTime: "45.2",        # Thời gian video hiện tại (giây)
  isPlaying: "true",          # Đang phát hay tạm dừng
  lastSyncAt: "1720278000",   # Unix timestamp lần sync cuối
  playbackRate: "1.0"         # Tốc độ phát
}
TTL: 24 hours

# Danh sách thành viên online
watchroom:{roomId}:members → SET [userId1, userId2, ...]
TTL: 24 hours

# Recent reactions (hiển thị floating)
watchroom:{roomId}:reactions → LIST [
  {"userId": 1, "emoji": "😍", "timestamp": 1720278000},
  ...
]
TTL: 30 seconds per entry
```

## 5. WebSocket Protocol (STOMP)

### 5.1 Connection & Authentication

```
STOMP CONNECT ws://server/ws
Headers: { Authorization: "Bearer {jwt_token}" }

SUBSCRIBE /topic/room.{roomId}.chat
SUBSCRIBE /topic/room.{roomId}.sync
SUBSCRIBE /topic/room.{roomId}.signal
SUBSCRIBE /topic/room.{roomId}.reaction
SUBSCRIBE /topic/room.{roomId}.presence
SUBSCRIBE /topic/room.{roomId}.system
```

### 5.2 Message Types

#### Chat Messages (`/topic/room.{id}.chat`)

```json
// Gửi
SEND /app/room.{roomId}.chat
{ "content": "Hay quá!", "messageType": "CHAT" }

// Spoiler
SEND /app/room.{roomId}.chat
{ "content": "Thằng kia chết ở cuối!", "messageType": "SPOILER" }

// AI trigger
SEND /app/room.{roomId}.chat
{ "content": "@AI phim này có bao nhiêu phần?", "messageType": "CHAT" }

// Nhận (broadcast)
{
  "id": 456,
  "userId": 1,
  "username": "tamdao",
  "avatarUrl": "...",
  "content": "Hay quá!",
  "messageType": "CHAT",
  "timestamp": "2026-07-06T20:05:30"
}

// AI response (broadcast)
{
  "id": 457,
  "userId": null,
  "username": "CineBot 🤖",
  "avatarUrl": "/bot-avatar.png",
  "content": "Phim Avengers có 4 phần chính...",
  "messageType": "AI_RESPONSE",
  "timestamp": "2026-07-06T20:05:32"
}
```

#### Video Sync Commands (`/topic/room.{id}.sync`)

```json
// Host/Co-host gửi
SEND /app/room.{roomId}.sync
{ "action": "PLAY", "timestamp": 45.2 }
{ "action": "PAUSE", "timestamp": 67.8 }
{ "action": "SEEK", "timestamp": 120.0 }
{ "action": "HEARTBEAT", "timestamp": 70.1 }  // Mỗi 5s

// Nhận (broadcast)
{
  "action": "PLAY",
  "timestamp": 45.2,
  "issuedBy": { "id": 1, "username": "tamdao" },
  "serverTime": "2026-07-06T20:05:30"
}
```

#### WebRTC Signaling (`/topic/room.{id}.signal`)

```json
SEND /app/room.{roomId}.signal
{
  "type": "OFFER",       // OFFER | ANSWER | ICE_CANDIDATE
  "targetUserId": 2,     // null = broadcast (for OFFER)
  "payload": "..."       // SDP hoặc ICE candidate JSON
}
```

#### Emoji Reactions (`/topic/room.{id}.reaction`)

```json
SEND /app/room.{roomId}.reaction
{ "emoji": "😍" }

// Nhận
{
  "userId": 1,
  "username": "tamdao",
  "emoji": "😍",
  "timestamp": "2026-07-06T20:05:30"
}
```

#### Presence Events (`/topic/room.{id}.presence`)

```json
// Tự động broadcast bởi server
{
  "type": "JOIN",      // JOIN | LEAVE
  "user": { "id": 1, "username": "tamdao", "avatarUrl": "..." },
  "memberCount": 6,
  "timestamp": "2026-07-06T20:05:30"
}
```

#### System Events (`/topic/room.{id}.system`)

```json
// Countdown
{ "type": "COUNTDOWN", "seconds": 5 }
{ "type": "COUNTDOWN", "seconds": 4 }
...
{ "type": "COUNTDOWN", "seconds": 0 }  // → Auto play

// Role change
{ "type": "ROLE_CHANGE", "userId": 2, "newRole": "CO_HOST" }

// Room ended
{ "type": "ROOM_ENDED", "message": "Host đã kết thúc buổi xem" }
```

### 5.3 Video Sync Protocol

```
Luồng đồng bộ video:

1. Host clicks Play →
   Host gửi STOMP: { action: "PLAY", timestamp: 45.2 }
   Server validate role (HOST/CO_HOST) → broadcast
   Server lưu state vào Redis
   Tất cả client → seek(45.2) → play()

2. Người mới vào phòng →
   GET /api/v1/watch-rooms/{id}/state → { currentTime: 67.8, isPlaying: true }
   Client → seek(67.8) → play()

3. Drift correction (mỗi 5 giây) →
   Host gửi HEARTBEAT: { action: "HEARTBEAT", timestamp: 70.1 }
   Client so sánh |localTime - serverTime|
   Nếu drift > 2s → auto seek(serverTime)
   Nếu drift ≤ 2s → adjust playbackRate tạm (1.05x hoặc 0.95x) để drift dần về 0
```

## 6. AI Bot Integration

### 6.1 Cơ chế hoạt động

```
User gửi: "@AI phim này hay không?"
  ↓
Server detect prefix "@AI" trong chat message
  ↓
Server gọi AIService (tái sử dụng module hiện có) với:
  - System prompt: "Bạn là CineBot, trợ lý AI trong phòng xem phim chung CineStream.
    Trả lời ngắn gọn, vui vẻ, dùng emoji. Tối đa 200 ký tự.
    Phim đang xem: {movieTitle}, thể loại: {categories}, diễn viên: {actors}"
  - User prompt: "phim này hay không?"
  ↓
Response broadcast qua /topic/room.{id}.chat
  messageType: "AI_RESPONSE"
  username: "CineBot 🤖"
```

### 6.2 Rate Limiting
- Max 5 AI requests/user/phút trong mỗi phòng
- Cooldown 3 giây giữa mỗi lần gọi AI

## 8. Tính năng đặc sắc

### 8.1 Floating Emoji Reactions
- User click emoji → broadcast qua STOMP → tất cả client render emoji bay từ dưới lên
- Animation: random horizontal offset, random size (1x-2x), fade out after 3s
- Android: Canvas-based rendering trên Compose
- Web: CSS animation hoặc canvas overlay

### 8.2 Cinematic Countdown
- Host nhấn "Bắt đầu xem" → Server broadcast countdown 5→1
- UI: Full-screen overlay, số lớn scale animation, flash effect, sound effect
- Khi = 0 → auto play video cho tất cả, overlay dissolve

### 8.3 Spoiler Alert System
- User gửi tin nhắn chọn type "SPOILER"
- Hiển thị: nội dung blur mờ + label "⚠️ SPOILER — Nhấn để xem"
- Click/tap → reveal animation (dissolve blur)
- Có thể ẩn lại

### 8.4 AI CineBot
- Trigger: prefix `@AI` trong chat
- Bot có avatar đặc biệt (robot neon cyan)
- Typing indicator: "CineBot đang suy nghĩ..." (shimmer animation)
- Trả lời ngắn gọn, vui vẻ, context-aware (biết phim đang xem)

### 8.5 Watch Party History
- Lưu lại mỗi buổi xem chung: phim, thời gian, thành viên
- Trang "Lịch sử Watch Party" hiển thị timeline
- Có thể tạo lại phòng từ lịch sử (cùng phim, mời lại thành viên cũ)

## 9. Bảo mật & Validation

### 9.1 Authentication
- WebSocket connection yêu cầu JWT token hợp lệ
- STOMP messages validate user identity từ security context
- REST API sử dụng JWT như hệ thống hiện tại

### 9.2 Authorization
- Chỉ HOST/CO_HOST mới gửi được sync commands (PLAY/PAUSE/SEEK)
- Chỉ HOST mới thay đổi role member
- Chỉ HOST mới kết thúc phòng
- Private room: cần mã phòng để tham gia
- Member bị kick không thể rejoin (trong phiên hiện tại)

### 9.3 Input Validation
- Room name: 1-100 ký tự, sanitize HTML/XSS
- Chat content: 1-500 ký tự, sanitize HTML/XSS
- Room code: 8 ký tự uppercase alphanumeric
- Max members: 2-50
- AI request: rate limit 5 req/user/min

### 9.4 Data Isolation
- User chỉ xem được messages của phòng mình đang tham gia
- Member list chỉ hiển thị cho thành viên phòng
- Validate room membership trên mọi WebSocket message

## 10. Error Handling

| Scenario | Response |
|----------|----------|
| Phòng đầy | 409 Conflict: "Phòng đã đầy" |
| Phòng không tồn tại | 404 Not Found |
| Mã phòng sai | 404 Not Found: "Mã phòng không hợp lệ" |
| Không có quyền sync | 403 Forbidden: "Chỉ host/co-host mới điều khiển video" |
| WebSocket disconnect | Auto-reconnect (3 lần, exponential backoff) → hiển thị toast "Mất kết nối" |
| WebRTC fail | Fallback voice-only → fallback text-only, hiển thị trạng thái |
| AI timeout | Hiển thị "CineBot không phản hồi, thử lại sau" |

## 11. Hiệu năng & Scalability

- **Redis** cho room state: O(1) read/write, không query MySQL cho real-time state
- **STOMP topics per room**: Tách biệt channels tránh crosstalk
- **Message batching**: Reactions batch mỗi 200ms trước khi broadcast
- **Chat pagination**: Load 50 tin nhắn gần nhất, load more khi scroll up
- **WebRTC mesh limit**: Max 10 camera streams, còn lại voice/text
- **Room cleanup**: Cron job dọn phòng ENDED quá 24h khỏi Redis
- **Lazy connection**: WebRTC chỉ khởi tạo khi user bật mic/cam
