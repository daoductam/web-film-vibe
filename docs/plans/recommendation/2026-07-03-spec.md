## 1. Overview
Introduce an Enterprise-grade Recommendation system using **Neo4j** as a graph database for fast relationship queries and **GraphQL** for clean client-server communication.
- **Home Screen:** "Personalized Recommendations" row tailored to logged-in users based on their graph interactions (Favorites and History). Hidden for guest users.
- **Movie Detail Screen:** "Similar Movies" section shown to all users, recommending movies with overlapping categories/genres.

---

## 2. Technical Stack Changes
- **Database:** Add Neo4j (Docker container) alongside MySQL and Redis.
- **Backend:** Add `spring-boot-starter-data-neo4j` and `spring-boot-starter-graphql`.
- **Frontend (Web):** Integrate `@apollo/client` or TanStack Query GraphQL.
- **Android:** Integrate Apollo Kotlin client.

## 3. Graph Schema Design (Neo4j)

### 3.1 Node Labels
- `User`: `{ username: String }`
- `Movie`: `{ id: Long, title: String, slug: String, posterUrl: String, views: Integer, rating: Float }`
- `Category`: `{ id: Long, name: String, slug: String }`

### 3.2 Relationship Types
- `(User)-[:FAVORITED]->(Movie)`
- `(User)-[:WATCHED { views: Integer, lastWatched: DateTime }]->(Movie)`
- `(Movie)-[:BELONGS_TO]->(Category)`

---

## 4. Graph Synchronization Protocol
MySQL remains the primary source of truth. The backend will sync changes asynchronously or via JPA lifecycle hooks:
1. **Movie / Category Created/Updated:** Sync nodes and `BELONGS_TO` edges to Neo4j.
2. **User Favorites / Watch History modified:** Add/update `FAVORITED` or `WATCHED` edges in Neo4j.

## 5. Recommendation Algorithms (Cypher)

### 5.1 Personalized Recommendations (Hybrid)
Recommend movies belonging to the user's favorite categories that they have not yet watched:
```cypher
MATCH (u:User {username: $username})
MATCH (u)-[r:FAVORITED|WATCHED]->(m:Movie)-[:BELONGS_TO]->(c:Category)
WITH u, c, SUM(CASE TYPE(r) WHEN 'FAVORITED' THEN 3.0 ELSE 1.0 END) AS categoryWeight
MATCH (candidate:Movie)-[:BELONGS_TO]->(c)
WHERE NOT (u)-[:WATCHED|FAVORITED]->(candidate)
WITH candidate, SUM(categoryWeight) AS score
RETURN candidate { .id, .title, .slug, .posterUrl, .views, .rating } AS movie, score
ORDER BY score DESC, candidate.views DESC
LIMIT 10
```

### 5.2 Similar Movies
Find movies sharing the most categories with the target movie:
```cypher
MATCH (m:Movie {slug: $slug})-[:BELONGS_TO]->(c:Category)<-[:BELONGS_TO]-(candidate:Movie)
WHERE candidate <> m
RETURN candidate { .id, .title, .slug, .posterUrl, .views, .rating } AS movie, COUNT(c) AS sharedCategoriesCount
ORDER BY sharedCategoriesCount DESC, candidate.views DESC
LIMIT 10
```

## 6. GraphQL Schema (`schema.graphqls`)

```graphql
type Movie {
  id: ID!
  title: String!
  slug: String!
  posterUrl: String
  views: Int
  rating: Float
}

type Query {
  personalizedRecommendations: [Movie!]!
  similarMovies(slug: String!): [Movie!]!
}
```
