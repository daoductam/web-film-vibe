# 1. Context

**Problem:**
CineStream lacks a personalized recommendation engine. Providing a recommendation row for logged-in users based on their activity (watch history and favorites) increases engagement, and showing similar movies on detail pages helps users find more content.

**Affected Modules:**
- `web-film-backend` — Implements Neo4j graph schemas, Cypher recommendations algorithms, data synchronization pipeline, and GraphQL endpoints.
- `web-film-frontend` — Integrates GraphQL client and adds recommendations UI to Home and Movie Detail pages.
- `web-film-android` — Integrates Apollo Kotlin client, updates ViewModels, and displays lists on Home Screen and Movie Detail Screen.

**Non-Goals:**
- Real-time deep learning recommendation models.
- Tracking anonymous guest history for recommendation (only logged-in users get personalized rows).

---

# 2. Constraints

**Language:** Java 21, TypeScript, Kotlin
**Architecture:** REST + GraphQL, Graph Database (Neo4j)

**Rules:**
- Maintain backward compatibility with existing MySQL and Redis components.
- Do not run heavy graph computations on MySQL.

**Performance Budgets:**
- GraphQL API Latency: < 100ms (p95) for recommendations.

---

# 3. Conventions

**Naming:**
- Neo4j Node Entities: `UserNode`, `MovieNode`, `CategoryNode`
- Neo4j Repositories: `MovieNeo4jRepository`, `UserNeo4jRepository`
- GraphQL Query Controllers: `RecommendationGraphQLController`

**Error Handling:**
- Wrap Neo4j synchronization failures so they do not block primary database writes.
- GraphQL queries fail gracefully by returning empty arrays rather than crashing the UI.

**Testing:**
- Framework: JUnit 5, Mockito (Backend), Jest (Frontend Web), Spek/MockK (Android).
- Naming: `should_<expected>_when_<condition>()`

# 4. Contracts

## Interface: `GraphSyncService`

```
syncMovieNode(movieId: Long): void
  - pre: movieId must exist in MySQL database
  - post: Movie node and BELONGS_TO Category edges are created/updated in Neo4j

syncUserNode(username: String): void
  - pre: user exists in MySQL
  - post: User node exists in Neo4j

syncFavoriteEdge(username: String, movieSlug: String, addRelation: boolean): void
  - pre: user and movie exist in Neo4j
  - post: FAVORITED relationship added or removed between User and Movie

syncWatchHistoryEdge(username: String, movieSlug: String): void
  - pre: user and movie exist in Neo4j
  - post: WATCHED relationship created/updated (increment views, update lastWatched)
```

## Data Schema: Neo4j Entities

```
UserNode {
  username: String (Unique Index)
}

MovieNode {
  id: Long (Unique Index)
  title: String
  slug: String
  posterUrl: String
  views: Integer
  rating: Float
}

CategoryNode {
  id: Long (Unique Index)
  name: String
  slug: String
}
```

# 5. Target Architecture

**Components:**
- `GraphSyncService` — Handles mapping and saving JPA entities to Neo4j.
- `RecommendationGraphQLController` — Exposes GraphQL queries.
- `MovieNeo4jRepository` — Performs Cypher queries for personalization and similarity.

**Interaction Flow:**

```
Client App (Web / Android)
  → GraphQL POST /graphql (personalizedRecommendations query)
    → RecommendationGraphQLController.personalizedRecommendations()
      → MovieNeo4jRepository.getRecommendations(username)
  ← returns GraphQL JSON response [ { id, title, slug, posterUrl, ... } ]
```

# 8. Task Specifications

## TASK-001: Setup Neo4j Infrastructure
- **Description:** Add Neo4j Docker service to `docker-compose.yml` with port mapping (7474 for Web Console, 7687 for Bolt protocol) and credentials.
- **Files:** `docker-compose.yml` (modify)
- **Acceptance Criteria:** `docker compose up -d` spins up neo4j successfully. Able to access `localhost:7474`.

## TASK-002: Configure Backend Dependencies
- **Description:** Add Spring Data Neo4j and Spring GraphQL dependencies to Maven pom. Configure credentials in `application.yml`.
- **Files:** `web-film-backend/pom.xml` (modify), `web-film-backend/src/main/resources/application.yml` (modify)
- **Acceptance Criteria:** Spring Boot starts up without connection errors to Neo4j.

## TASK-003: Define Neo4j Graph Entities & Repositories
- **Description:** Implement `@Node` and `@Relationship` classes, and Spring Data Repositories using `@Query` for the Cypher algorithms specified in the Spec.
- **Files:**
  - `web-film-backend/.../entity/neo4j/UserNode.java` (create)
  - `web-film-backend/.../entity/neo4j/MovieNode.java` (create)
  - `web-film-backend/.../entity/neo4j/CategoryNode.java` (create)
  - `web-film-backend/.../repository/neo4j/MovieNeo4jRepository.java` (create)
- **Acceptance Criteria:** Repository queries return correctly mapped entity objects in tests.

## TASK-004: Implement Data Sync Pipeline & Event Listeners
- **Description:** Implement GraphSyncService. Setup Spring Transactional Event Listeners to asynchronously replicate MySQL user, movie, category, favorite, and history modifications to Neo4j. Add a migration endpoint to initial sync existing DB data.
- **Files:**
  - `web-film-backend/.../service/GraphSyncService.java` (create)
  - `web-film-backend/.../listener/GraphSyncEventListener.java` (create)
- **Acceptance Criteria:** Saving a favorite movie adds a `FAVORITED` edge in Neo4j.

## TASK-005: Create GraphQL Recommendation Endpoints
- **Description:** Expose `personalizedRecommendations` and `similarMovies` GraphQL queries.
- **Files:**
  - `web-film-backend/src/main/resources/graphql/schema.graphqls` (create)
  - `web-film-backend/.../controller/RecommendationGraphQLController.java` (create)
- **Acceptance Criteria:** Running the GraphQL queries via GraphiQL returning recommendations lists.

## TASK-006: Implement Frontend Web Recommendation UI
- **Description:** Integrate Apollo client/GraphQL requests. Update Home Page to show personalized recommendations row (if logged in) and update detail page with similar movies list.
- **Files:**
  - `web-film-frontend/src/components/movie/PersonalizedRecommendations.tsx` (create)
  - `web-film-frontend/src/components/movie/SimilarMovies.tsx` (create)
- **Acceptance Criteria:** Web app displays list correctly.

## TASK-007: Implement Android Recommendation UI
- **Description:** Setup Apollo Kotlin compiler. Write GraphQL query documents, compile generated models. Integrate inside Home Screen and Detail Screen ViewModels, rendering list.
- **Files:** Android codebase files (create/modify)
- **Acceptance Criteria:** Android UI functions seamlessly with real-time graph recommendations.
