# Thiết kế Tính năng Điều chỉnh Giao diện Sáng/Tối (Theme Selection)

Tài liệu thiết kế chi tiết cho việc tích hợp tính năng đổi giao diện (Sáng, Tối, Hệ thống) trên ứng dụng Android CineStream.

## Mục tiêu
Cung cấp khả năng chuyển đổi giao diện động trên ứng dụng Android CineStream, hỗ trợ 3 chế độ:
1. **Sáng (Light Mode)**: Phục vụ trải nghiệm đọc và lướt phim ở môi trường nhiều ánh sáng.
2. **Tối (Dark Mode)**: Giao diện Obsidian mặc định sang trọng.
3. **Theo hệ thống (System Default)**: Tự động đổi theo cài đặt hệ thống của Android.

## Chi tiết Thiết kế

### 1. Quản lý Trạng thái Giao diện (SessionManager & Preferences DataStore)
* Thêm key `THEME_MODE` trong `SessionManager.kt` lưu giá trị kiểu String: `"LIGHT"`, `"DARK"`, `"SYSTEM"`.
* Mặc định là `"SYSTEM"`.
* Cung cấp Flow `themeMode: Flow<String>` để các UI component lắng nghe.
* Cung cấp hàm `suspend fun setThemeMode(mode: String)` để lưu lựa chọn mới của người dùng.

### 2. Thiết lập Hệ màu (Color & Theme)
Cập nhật `Color.kt` và `Theme.kt` để định nghĩa Light Color Scheme:

```kotlin
// Light Scheme Colors (Premium Slate & Blue Cyan)
val LightBackground = Color(0xFFF8FAFC)
val LightSurface = Color(0xFFFFFFFF)
val LightTextPrimary = Color(0xFF0F172A)
val LightTextSecondary = Color(0xFF475569)
val DeepCyan = Color(0xFF007A87)
val LightSurfaceDim = Color(0xFFE2E8F0)
```

Cập nhật `Theme.kt`:
* Cập nhật `CineStreamTheme` để nhận thêm tham số `themeMode: String` hoặc tính toán trực tiếp `darkTheme: Boolean` từ `MainActivity` hoặc sử dụng `isSystemInDarkTheme()`.
* Chuyển trạng thái StatusBar và NavigationBar màu động tùy theo theme sáng/tối.

### 3. Cập nhật Giao diện các Màn hình (Dynamic UI Colors)
Thay thế việc sử dụng các màu cứng `Obsidian`, `Color.White`, `Color.Gray` sang các màu ngữ nghĩa từ `MaterialTheme.colorScheme`:
* `Obsidian` -> `MaterialTheme.colorScheme.background`
* `Color.White` -> `MaterialTheme.colorScheme.onBackground` hoặc `MaterialTheme.colorScheme.onSurface`
* `SurfaceDark` -> `MaterialTheme.colorScheme.surface`

*Lưu ý: Màn hình trình phát video (`VideoPlayerScreen`) sẽ luôn luôn giữ giao diện màu Tối (Dark/Black) để tập trung trải nghiệm xem phim.*

### 4. Giao diện Cài đặt trên Profile Screen
* Thêm một mục "Giao diện" trong `ProfileScreen.kt` hiển thị lựa chọn hiện tại (ví dụ: "Sáng", "Tối", "Theo hệ thống").
* Khi nhấn vào, hiển thị một Dialog (`AlertDialog`) danh sách 3 RadioButton tương ứng để người dùng lựa chọn.
* Khi người dùng chọn, gọi ViewModel để cập nhật cấu hình thông qua `SessionManager`.
