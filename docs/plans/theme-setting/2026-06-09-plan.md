# 1. Context

**Problem:**
The CineStream Android application currently has a hardcoded dark theme (Obsidian background and white texts). Users cannot switch to a light theme or follow their system settings for theme adjustment.

**Affected Modules:**
- `core/session` — Core preferences storage to persist theme choice.
- `ui/theme` — Theme definition (Color schemes, theme wrapper).
- `MainActivity.kt` — App entry point that hosts the NavHost and root theme.
- `feature/profile` — Profile Screen UI to let users switch themes.
- `feature/home`, `feature/search`, `feature/library` — Key screens that need to use dynamic theme color schemes instead of hardcoded background colors.

**Non-Goals:**
- Dynamically switching video player colors (the video player MUST remain dark/black at all times).
- Modifying backend APIs (theme preference is saved purely client-side).

---

# 2. Constraints

**Language:** Kotlin  
**Architecture:** MVVM + Clean Architecture  

**Rules:**
- Do NOT introduce any new external libraries or dependencies.
- Maintain full compatibility with current screens and layout structures.
- Status bar text/icon colors must be readable in both light and dark modes.

---

# 3. Conventions

**Naming:**
- Theme Constants: `THEME_LIGHT`, `THEME_DARK`, `THEME_SYSTEM`
- Methods: `themeMode`, `setThemeMode`

**Testing:**
- Manual verification of UI across Light, Dark, and System Default options.

---

# 4. Contracts

## Data Store Preferences: `SessionManager`
```kotlin
SessionManager.themeMode: Flow<String>
  - post: Emits current theme mode string ("LIGHT", "DARK", or "SYSTEM"). Defaults to "SYSTEM".

SessionManager.setThemeMode(mode: String)
  - pre: mode must be one of "LIGHT", "DARK", or "SYSTEM"
  - post: Saves the choice in Preferences DataStore.
```

---

# 5. Target Architecture

**Interaction Flow:**
```text
ProfileScreen (User Selects Theme)
  → ProfileViewModel.setThemeMode(mode)
    → SessionManager.setThemeMode(mode)
      → (Flow update triggers)
        → MainActivity (re-evaluates isDarkTheme)
          → CineStreamTheme(darkTheme = isDarkTheme)
            → MaterialTheme color scheme switches
```

# 8. Task Specifications

## TASK-001: Persist Theme Preference in SessionManager & MainActivity
- **Description:** Implement DataStore preferences to store theme mode and collect it in MainActivity.
- **Files:**
  - `app/src/main/java/com/tamdao/cinestream/core/session/SessionManager.kt` — **modify**: Add `THEME_MODE` key, `themeMode` flow, and `setThemeMode` function.
  - `app/src/main/java/com/tamdao/cinestream/MainActivity.kt` — **modify**: Inject `SessionManager` and collect `themeMode` as state. Pass the mode or computed boolean to `CineStreamTheme`.

## TASK-002: Define Light Color Scheme & Dynamic CineStreamTheme
- **Description:** Define the new Slate-Teal colors and update `CineStreamTheme` to resolve the scheme dynamically based on both user selection and system default.
- **Files:**
  - `app/src/main/java/com/tamdao/cinestream/ui/theme/Color.kt` — **modify**: Add light theme colors (`LightBackground`, `LightSurface`, `LightTextPrimary`, `LightTextSecondary`, `DeepCyan`, etc.).
  - `app/src/main/java/com/tamdao/cinestream/ui/theme/Theme.kt` — **modify**: Define `lightColorScheme`, update `CineStreamTheme` to take `themeMode: String` or a boolean indicator, and adjust status bar text color based on light/dark mode.

## TASK-003: Build Theme Selector Dialog in Profile Screen
- **Description:** Add the "Giao diện" item to the Profile screen options, and show an AlertDialog with radio choices to save selection to preferences.
- **Files:**
  - `app/src/main/java/com/tamdao/cinestream/feature/profile/ProfileViewModel.kt` — **modify**: Add `themeMode` state flow and `setThemeMode(String)` launcher.
  - `app/src/main/java/com/tamdao/cinestream/feature/profile/ProfileScreen.kt` — **modify**: Add theme switcher menu item, dialog UI, and trigger settings update.

## TASK-004: Adopt Semantic Theme Colors across Main Screens
- **Description:** Swap hardcoded dark colors to semantic theme colors so screens swap colors dynamically.
- **Files:**
  - `app/src/main/java/com/tamdao/cinestream/feature/home/HomeScreen.kt` — **modify**
  - `app/src/main/java/com/tamdao/cinestream/feature/search/SearchScreen.kt` — **modify**
  - `app/src/main/java/com/tamdao/cinestream/feature/library/LibraryScreen.kt` — **modify**
  - Core components (`CineBottomBar`, etc.) if needed.

## TASK-005: Manual Verification & Polish
- **Description:** Compile the project and verify correct color rendering across Light/Dark/System modes. Ensure video player remains dark.
